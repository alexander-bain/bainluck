# Subcohort Views — calibration ECE by league × source × market_type × band × week

This directory documents the cohort drill-down that powers `GET /api/admin/cohort-market-type` and the admin pages. Every cell is an intersection of source (polymarket/kalshi/odds_api…), league/category, market_type (quantity/container_member/field/duel…), probability band (0–10%…90–100%), and week, ranked by ECE (expected calibration error, n-weighted 10-bin |actual−predicted| in pp). The worktree is `~/bainluck/.claude/worktrees/codex-adhoc` on branch `codex-adhoc/cohort-views`.

**`GET /api/admin/cohort-market-type` (heavy, cached)** measures the canonical published calibration population — the exact `deduped` CTE from `app.tasks.precompute_calibration._calibration_population_ctes` (field-completeness, mode-price and tail dedup, rn=1 binary-side, virtual-market identity), grouped into cells with n, independent_questions, ECE, gap, graded_share, and verdict (GREEN ≤5pp else RED else NOT-PROVABLE; graded_share<0.5 always NOT-PROVABLE-selection-biased and wins before GREEN). Refresh via `POST /api/admin/cohort-market-type/build` (header-only `Authorization: Bearer`, enqueued to Celery `heavy` queue ~90s, cached at `bainluck:cohort_market_type` for 24h); the UI shows `generated_at` and a red STALE badge when age>6h with a Rebuild button, so a stale number never renders silently.

**`GET /api/admin/cohort-market-type/light` (light-estimate, synchronous)** measures the same cell keys but on a fast 200k-row sample (`futures_outcomes JOIN futures_markets WHERE status='resolved'` and `opening_probability IS NOT NULL`, no dedup/field-normalization), computing ECE per cell in Python via the single canonical `_compute_horizon_mce` and labeling every row and the payload `ece_label: "light-estimate"` (and `fallback-nonparity` if the canonical import ever fails). It exists to test a hypothesis in <10s while the heavy build runs; the note says "canonical heavy build is the source of truth" and parity on a full-population cell is asserted to 0.01pp in `tests/evals/test_cohort_ece_parity.py`.

**`GET /api/admin/cohort-market-type/weekly` (time)** measures ECE per cohort per week for the last six weeks (`resolution_week = DATE_TRUNC('week', resolution_date)`), so the Monday scoreboard can quote `weekly_by_cohort[cohort].map(week→ECE)` and answer "is it improving?" — it is populated by the same heavy build as the main table and shares its STALE/Rebuild semantics.

**`GET /api/admin/cohort-provenance-split` (venue-graded vs all)** measures the decisive provenance experiment for the worst shape cells (polymarket quantity/container_member by league, ECE 30–50pp) by recomputing ECE twice per cell: all rows vs `resolution_source IS NOT NULL` only, plus `null_default_share` and `graded_share`. If the 30–50pp collapses on venue-graded only, the overconfidence is the fabricated `is_winner=false` default on ~226k never-graded markets (fix: backfill #1912, exclude `NULL` from calibration); if it survives, it is a real normalization defect. Header-only auth; ECE via the same canonical `_compute_horizon_mce`.

**`GET /api/admin/cohort-sums-histogram` (sums-to-1, conditional)** measures the normalization defect only if provenance survives: per-group `SUM(curve_price)` for container_member/quantity ladders grouped by `COALESCE(group_id, event_id)`, histogrammed into buckets 0–1.0, 1.0–1.5, 1.5–2.0, 2.0–3.0, 3.0–5.0, 5.0+ plus per-size median/avg and a venue-graded-only histogram. A healthy ladder sums ~1.0 independent of members; a ladder defect treated as independent binaries at raw price sums 2–5 (e.g., 5×0.50=2.50). Header-only auth.

**`GET /api/admin/cohort-views` (HTML) and `frontend/app/admin/cohort-views/page.tsx` (Next.js)** measure nothing themselves — they render the heavy table sorted desc by ECE with graded_share, band, verdict, and the weekly trend, auto-refreshing every 60s, showing `generated_at` + STALE (>6h) and a header-auth Rebuild button; the HTML holds the token in-memory only (`_inMemoryToken`), never in URL or browser storage. To refresh any view: open the admin page, click Rebuild (or `curl -H "Authorization: Bearer $ADMIN_TOKEN" -X POST https://api.bainluck.com/api/admin/cohort-market-type/build`), wait ~90s, then `GET` again.
