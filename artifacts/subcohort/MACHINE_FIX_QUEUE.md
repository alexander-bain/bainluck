## Re-baseline — what "fixed once and for all" means

- Heavy deduped build `POST /api/admin/cohort-market-type/build` → `GET /api/admin/cohort-market-type` (canonical `by_ece`, `by_band_worst`, `weekly_by_cohort`, `independent_questions`/`q`, `ece_pp` + `ece_label`, `graded_share` + `verdict`). - No cold-cache `5000.00` render: `ece_label` branches scaling (`light-estimate` already pp).

**What gets published alongside ECE (audit §5):**
- **Brier** `AVG((p-y)^2)` + **reliability** `Σ n_b/N (actual_b - avg_p_b)^2` + **resolution** `Σ n_b/N (actual_b - base_rate)^2` + **uncertainty** `base_rate(1-base_rate)` + **sharpness** (histogram of `p`) — so ECE's absolute error is not quoted alone. Reliability is ECE²'s twin; resolution tells if the market distinguishes winners at all.
- **Adaptive (equal-mass) ECE** and **debiased ECE** as secondary cols, plus per-bucket `n` so a 10-bin ECE with empty tails is not quoted bare.
- **Per-bucket n** and **per-market `q`** so `n=2880/q≈576` ladders are read correctly.
