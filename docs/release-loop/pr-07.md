Starting Tuesday, November 3, this PR builds and uploads Bain Luck to TestFlight after every master merge touching iOS, using a separate hosted Mac and the native lane's existing App Store Connect key. Each first-parent iOS commit in a batched push gets its own release run, including changes later reverted in that same push; each run builds the exact selected code, validates ownership again on failed-job retries, and gets the next build number above Apple, master and build 99; if neither Apple nor master has advanced, the first is 1.0.5 build 100. The action checks the archived and exported app and extensions, then waits for Apple's successful processing and keeps the binary and receipt. The required API-key and distribution-signing secrets are documented in docs/release-loop/testflight-setup.md and remain unverified in this internet-disabled session; local controller tests pass, while the first signed hosted build remains the activation check.
