This Tier-B PR gives production releases an unattended health check and automatic rollback, with one verdict line on the NOW issue. Heroku's signed release event and Vercel's controlled promotion start the check, which fetches anonymous /api/feed?limit=5 and /api/health and runs the existing worker checks. The operational guard still stops after two sampled minutes in a row over **5,000 ms**, excluding na_orientation; guard3 retains its **three-minute over-5,000-ms** stop and **20-percentage-point** deterioration rule for minutes under 500 ms. Rollback uses a verified working source, and a failed-source veto prevents a later Vercel promotion from undoing the watchdog's decision. A private, bounded Redis log collector preserves startup and latency evidence across restarts and queued runners; missing or lost evidence stays UNKNOWN. Local tests cover stale releases, failed-source vetoes, replayed or truncated logs, authentication, bootstrap holds, and import safety. Setup explicitly seeds reviewed existing watcher evidence before the first release, then uses full-CI bootstrap before enabling the fast lane. Collector destination confirmation, real provider checks, frontend build/typecheck, and Alex's “master is current” remain activation gates.
