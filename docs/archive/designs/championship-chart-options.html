Championship Grid Chart Redesign

MLB World Series odds — real data from bainluck.com (March 27 – April 2, 2026)

Current (broken)

The existing spaghetti chart. Lines are bunched together, no visible axes, impossible to read on mobile. This is what we're replacing.

Option A: Bump / Rank Chart

Recommended Mobile ✓

Y-axis shows rank (1st at top), not raw probability. Lines cross when teams swap positions. Eliminates the bunched-up spaghetti problem because vertical spacing is fixed.

✓ Strengths

  • Always readable — fixed vertical spacing
  • Shows movement clearly (line crossings)
  • Works at any scale (1% and 30% are equally visible)
  • Great on mobile (no tiny differences to parse)

✗ Weaknesses

  • Loses absolute probability info (rank ≠ probability)
  • A team going 5.0% → 5.2% could swap rank and look dramatic
  • Less familiar chart type for casual fans

Option B: Interactive Highlight

Best on Desktop

All lines shown muted. Tap a team name to spotlight that line. Top 3 highlighted by default. Legend doubles as filter buttons.

✓ Strengths

  • Shows real probabilities (not just rank)
  • Users can explore specific teams
  • Progressive disclosure — not overwhelming

✗ Weaknesses

  • Requires interaction to be useful
  • Muted lines still look like spaghetti
  • Tap targets small on phone
  • Bunching problem persists for non-highlighted teams

Option C: Sparklines in Grid

Mobile ✓

Kill the standalone chart. Instead, embed a tiny sparkline next to each team's probability in the grid table itself. Each team's trend is self-contained.

# Team Prob 7d Trend

✓ Strengths

  • No separate chart — data and trend in one view
  • Each team's line is crystal clear
  • Scales to any number of teams
  • Extremely mobile-friendly

✗ Weaknesses

  • Can't compare teams' trends visually against each other
  • Tiny sparklines have limited resolution
  • Loses the "story" of who's gaining vs falling
  • Might feel sterile — less visually exciting

Option D: Small Multiples

Best on Desktop

Top 6 teams each get their own mini area chart in a 2×3 grid. Each chart has its own Y-axis scaled to the team's range. Clean and readable.

✓ Strengths

  • Each team's trend is perfectly clear
  • Area fills make movement feel tangible
  • Can see relative movement across teams at a glance
  • Familiar chart format (small multiples are well-understood)

✗ Weaknesses

  • Uses significant vertical space (especially on mobile)
  • Y-axis scales differ per team — misleading if not careful
  • Only shows top N teams — others are invisible
  • 2-column layout on phone means very small charts

Option E: Horizontal Bars + Sparklines

Recommended Mobile ✓

Current snapshot as a horizontal bar chart (biggest at top) with a 7-day sparkline next to each bar. Best of both worlds: current state + recent trend.

✓ Strengths

  • Instantly shows who's leading (bar length)
  • Sparkline adds trend without complexity
  • Natural sort order (biggest at top)
  • Excellent on mobile — no interaction needed
  • Easy to scan 30+ teams

✗ Weaknesses

  • Sparklines are tiny — limited trend detail
  • Doesn't show exact historical values
  • Bar dominance (Dodgers at 31%) makes other bars tiny
