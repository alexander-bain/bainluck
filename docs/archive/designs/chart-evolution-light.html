Variant B

Pill Toggles

Same clean chart, but pill buttons replace the sidebar. Better touch targets for mobile — no dropdown needed. Top 3 pre-selected. All teams visible and tappable.

Mobile advantage Pills are easier to tap on phones than dropdowns. Pre-selected top 3 means the chart is useful immediately with zero interaction. Scrollable row on narrow screens.
Variant C

Search + Tags

Type-ahead search above the chart to add teams. Selected teams shown as colored tags. Best for large fields (golf with 50+ players, NCAA with 64+ teams) where showing all as pills doesn't scale.

Time Range
World Series 2026 Type to search · Click tag to remove
Scales best When there are 50+ players or 30+ teams, pills don't fit. Search-to-add scales to any field size. Pre-populated with top 3 so the chart is never empty on load.

Which interaction model?

The chart itself is identical across all three — the difference is how you select teams/players. We can also combine (e.g., pills on desktop, search on mobile).
