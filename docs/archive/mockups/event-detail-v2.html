Event Detail v2

Design Brief

Comprehensive Event Detail Page

All three options share the same 4-level hierarchy and the same data. They differ in layout density, visual emphasis, and how they handle the live-vs-completed distinction. All use the existing ProgressionLadder cards for playoff path. All surface game-level props from Kalshi (spreads, totals, 1st half, player props) that we're currently ingesting but not displaying.

Level 1 -- Win Probability
Hero section with probability, score, opening odds. Chart with quarter markers integrated into the chart line (not a ribbon). "Since Start" default for completed games.
Level 2 -- Projected Score
Spread + Total from Kalshi/sportsbooks. Shows projected final score, actual vs predicted. For completed games: "Market said X, actual was Y."
Level 3 -- Game Props
1st half winner, player stat props (30+ points, 10+ rebounds), game-specific markets from Kalshi. Show opening line, current, and actual result.
Level 4 -- Season Context
Playoff path (ProgressionLadder cards), awards, stat leaders, matchup markets, win totals, trades. Grouped and deduped across sources. Fascinating when they move during a game.

What's new vs. today

  • Spread + Total markets surfaced as "Projected Score" (Level 2 -- currently unused)
  • Player props + 1st half markets surfaced as "Game Props" (Level 3 -- currently unused)
  • Playoff path uses existing ProgressionLadder from MyStuff
  • Cross-source merge on Level 4 futures (3 NBA Champion rows become 1)
  • "Since Start" default for completed games
  • Actual vs predicted comparison on completed game props
  • Source dots on every merged item
  • Game props (spreads, totals, player props) are in futures_markets DB but not currently linked to events -- needs a new query path
  • Cross-source merge requires server-side grouping by merge_group (not done yet)
  • Some Kalshi game props might not have merge_group assigned

Version 1

Stacked Sections

Clean vertical flow. Each level gets its own section with a clear header. Scrolling down is a journey from "what's happening now" to "what does this mean for the season." Good for both live and completed games.

Pros

  • Most natural reading order -- top to bottom = most to least important
  • Each section standalone, easy to scan
  • Section headers with counts give overview
  • Works well on narrow mobile screens
  • Easiest to implement -- just add sections below chart

Cons

  • Long page -- Level 4 is far down
  • Less information density than dashboard layout
  • May feel "listy" for the futures sections

Version 2

Score-Forward

Integrates the projected score directly into the hero, making it Level 1.5. The hero becomes a "prediction card" that shows: actual score, win prob, spread, and total in one block. Game props sit immediately below as a natural extension of "what happened in this game." Season context follows.

Pros

  • Score context immediately visible -- user sees spread + total without scrolling
  • Hero tells a complete story: who won, by how much, vs prediction
  • Game props feel connected to the game, not separate
  • More compact -- less scrolling to reach Level 4

Cons

  • Denser hero might feel cluttered for casual users
  • Spread/total less relevant for sports without those markets
  • Score-forward emphasis may not work for pre-game state

Version 3

Live Dashboard

Optimized for watching a live game. All 4 levels visible without scrolling. Uses a compact 2-column grid for Level 3 and Level 4. The hero is slim, the chart is taller (it's the star), and everything else packs below in a dashboard-style grid. When a future MOVES during the game, it gets a visual "movement" indicator.

Pros

  • Maximum information density -- all 4 levels in one viewport
  • Best for live games -- watch everything update in real-time
  • Movement indicators show which futures are shifting right now
  • Grid layout feels like a professional dashboard
  • Chart gets more vertical space (the hero product)

Cons

  • Very dense -- may overwhelm casual users on first visit
  • 2-column grid tight on 375px phones
  • Harder to show all awards/trades without scrolling within cards
  • Movement indicators need real-time data to be meaningful
Movement indicators
When a future's probability changes during a live game, it gets a colored arrow (green up, red down) and briefly highlights. This is the "FASCINATING when they move during a game" feature.
