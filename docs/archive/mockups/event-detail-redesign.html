Now for the main event: how should we organize the 176 related futures?

Option A

Grouped Cards

176 items collapsed into ~12 smart cards. Each card shows a summary (best probability, source count) and expands to reveal every outcome and per-source breakdown. Cross-source items are merged into single rows with aggregated probability.

Key Behaviors

  • Playoff Progression card shows path as a horizontal bar chart
  • Cross-source merge: "NBA Champion = 13.5% (3 sources)" instead of 3 separate rows
  • Source dots (blue/green/purple) at a glance show which sources have data
  • Matchup markets shown as ranked list within one card
  • Win totals show the "interesting threshold" (nearest 50%) prominently
  • Resolved items (>99% or <1%) render in muted style but remain visible
  • Tap any merged row to see per-source breakdown inline

Pros

  • Most natural hierarchy -- summary to detail in one scroll
  • Best for the "176 items that feel like 15" goal
  • Progression visualization is compelling
  • Cards can be reordered by relevance dynamically

Cons

  • Long page when multiple cards expanded
  • Grouping logic must be very accurate -- wrong group = confusion
  • More complex server-side logic needed

Option B

Tabbed Categories

Horizontal tab bar segments futures by category: Playoff, Matchups, Awards, Stats, Trades, Other. Each tab shows a flat list of merged items with inline probability bars and source indicators. Cross-source merging still happens, but grouping is flatter.

Pros

  • Familiar pattern (like app store categories)
  • Tab counts show how many items per category at a glance
  • Each tab is focused -- no overwhelming scroll
  • Easier to implement than Option A (less grouping logic)
  • Works well on mobile -- tabs scroll horizontally

Cons

  • Harder to see relationships BETWEEN categories (playoff path spans multiple)
  • Progression visualization less natural in a flat list
  • Tab switching adds friction vs. scrolling
  • Doesn't reduce cognitive load as much as cards -- still a list

Option C

Compact Dashboard

A 2-column grid of compact cards, each showing a single "hero stat" for its category. Tap any card to expand into a full detail view (modal or inline). Inspired by Apple Health / Fitness app summary cards.

Pros

  • Maximum information density -- see everything at a glance
  • Tappable cards feel modern and interactive
  • Each card can use custom visualization for its type
  • No scrolling past 20+ items to see the bottom categories
  • Best for users who want a quick overview, not deep exploration

Cons

  • Less room for detail in the summary view
  • Two-column grid might feel cramped on mobile (375px)
  • Expansion interaction needs careful design (modal vs inline?)
  • Harder to show the "progression" story inline
  • May feel more like a dashboard than a story about this team
