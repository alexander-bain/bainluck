How it works: Kalshi/Polymarket offer binary "Team wins by X+" contracts at multiple thresholds. We interpolate the 50% probability crossover to derive an implied spread — comparable to the sportsbook line, but from prediction markets. When the implied spread diverges from the actual score differential, it signals where the market thinks the game is heading.

Note: Both Kalshi and Polymarket offer binary spread + total contracts for all major US sports. Polymarket also has player props (Points, Assists, Rebounds). Sportsbook spread is always a single number. All prediction market spreads/totals use the same binary contract structure — derive implied values identically.

6. Implementation Plan

Phase 1: Backend — Binary-to-Spread Utility

New utils/binary_spread.py

  • binary_to_implied_spread(contracts) — interpolate 50% crossover from threshold/probability pairs
  • binary_to_implied_total(contracts) — same logic for total points contracts
  • projected_final_score(spread, total) — returns {home: (total+spread)/2, away: (total-spread)/2}
  • Works for both Kalshi and Polymarket binary contracts (future-proof)

Phase 2: Backend — History Endpoint

Add kalshi_spread + kalshi_total to event history response

  • Query futures_odds_snapshots for matched spread/total binary contracts
  • At each snapshot timestamp, run binary_to_implied_spread() to derive the spread
  • Return as time series alongside existing score_history and odds history

Phase 3: Frontend — Score Differential Chart

  • Purple dashed line for Kalshi implied spread
  • Pink dashed line for Polymarket when available
  • Current value labels on right edge
  • Togglable in legend (on by default when data exists)

Phase 4: Frontend — Binary Contract Curves

  • Collapsible section below Score Differential chart
  • Bar chart showing each threshold's probability
  • Annotated 50% crossover point
  • Side-by-side for Spread and Total Points

Phase 5: Frontend — Projected Final Score

  • Pre-game: large projected score card + 48h spread trend chart
  • Live: compact "Current vs Projected" comparison card
  • Combine best available spread + total (Kalshi > Sportsbook fallback)
